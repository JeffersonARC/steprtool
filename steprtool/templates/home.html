Home Page for JeffersonARC Remote

This is the place to come for using any of the club's remotely controlled radios. From here you can:

  • find out if the antennas have been disconnected for lightning
  • post a message for other remote operators
  • book operations time in advnce in the calendar
  • control the SteppIR antenna's SDA 100 antenna controller
  • go to the webpage to use ECHOCAT to control the IC-7300
  • (and someday control the SteppIR rotator>)

Please always come to this page first when planning to operate any of the radios remotely, so other operators can see who is here.

The lightning detection is not 100% accurate, so if you are CERTAIN, the banner is wrong, you can change the state by adding query parameters to the URL, like this: https://100.98.246.94:6300?antennas=connected&callsign= `<your callsign> (or disconnected)

To be added to the mailing list for remote operations, email remote@w5gad.org
